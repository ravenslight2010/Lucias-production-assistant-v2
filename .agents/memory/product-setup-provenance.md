name: Product setup provenance
description: Preserve uncertain imported production-line and allergen details until product-specific manager review.
---

Imported production-line values and allergen notes are evidence, not selected product defaults. Preserve missing values and disagreements explicitly; only use the value an owner or manager reviewed and saved for that product.

**Why:** The user requested product-scoped line and allergen defaults and explicitly said missing or conflicting imported values must remain explicit instead of being guessed.

**How to apply:** Keep source evidence traceable in manager review and future run snapshots. Do not auto-select among conflicting line candidates, infer an allergen list from notes, or rewrite existing runs when profile defaults change.
